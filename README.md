# Kanri

モンスターストライクの所持モンスターを管理するWebアプリです。

## できること

- **図鑑**: ゲームの「モンスター図鑑」の一覧画面のスクショから、名前と一覧に出すアイコンだけを登録します。縦長のスクショなら、最初の枠がアイコン1つ分の大きさで左上のアイコンに合い、「次のアイコン」で順に進めます（保存すると自動で次へ進みます）。
- **図鑑の詳細**: 図鑑のアイコンを押すと詳細画面が開き、ゲームの「モンスター詳細画面」などのスクショを何枚でも追加できます。追加するときに不要な部分（ステータスバーなど）を切り取ります。詳細画面の写真からは、図鑑No.と属性を自動で読み取って入れます（OCRのデータは `public/tessdata/` に同梱していて、読み取りは端末内で完結します）。
- **所持**: 図鑑からモンスターを選んで所持に追加し、ラック（運極）・メモ・お気に入りを管理します。名前・図鑑No.・属性で絞り込めます。
- **設定**: データをJSONで書き出し・復元できます。

データはすべて端末のブラウザ内（IndexedDB）に保存され、サーバーには送られません。

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm run build   # 本番ビルド (dist/)
npm run lint
```

## 公開

`main` に push すると GitHub Actions で GitHub Pages にデプロイされます。
初回だけ、リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください。

## 構成

Vite + React + TypeScript、Dexie (IndexedDB)。デスクトップ版は将来 Tauri で包む想定です。
